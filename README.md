## Objetivos del Proyecto

### Objetivo General
Crear una base de datos digital estudiantil para facilitar consultas rápidas de enfermería y reducir el uso de registros en papel.

### Objetivos Específicos
* Desarrollar la plataforma web escolar para organizar datos de salud estudiantil.
* Registrar información médica de los estudiantes y mejorar el control sanitario.
* Actualizar registros médicos periódicamente y generar reportes de control.
* Digitalizar la toma de registros en prácticas formativas.

## Identidad Visual y Marca

El proyecto fue desarrollado respetando estrictamente los lineamientos del **Manual de Marca de SAMGY**:

* **Colores Institucionales:**
  * **Azul Oscuro Institucional:** `#03658C` (Representa seguridad y confianza).
  * **Azul Claro Clínico:** `#4FB3D9` (Genera tranquilidad en entornos de salud).
  * **Gris Suave Profesional:** `#D9E2E8` (Aporta equilibrio y estabilidad).
  * **Blanco Hospitalario:** `#FFFFFF` (Asociado con higiene y orden).
* **Tipografías:**
  * **Montserrat:** Títulos y encabezados principales.
  * **Open Sans:** Textos de contenido y lectura clínica.
